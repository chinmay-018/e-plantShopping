# Paradise Nursery - E-Plant Shopping Application

A responsive React and Redux-powered web application for browsing houseplants and managing a digital shopping cart. Built as part of the IBM Front-End Developer specialization capstone.

## Features
- **Landing Page:** Interactive splash screen introducing Paradise Nursery with direct navigation to the plant catalog.
- **Product Catalog:** Plants grouped into distinct categories (Air Purifying, Aromatic) with pricing and descriptions.
- **State Management:** Redux Toolkit manages global cart state, item quantities, and real-time cart badge counts.
- **Cart Operations:** Dynamic increment, decrement, and item removal with auto-calculated subtotals and grand totals.

## Technologies Used
- React.js (Hooks & Functional Components)
- Redux Toolkit & React-Redux
- CSS3 (Flexbox & CSS Grid)
- GitHub Pages Deployment
